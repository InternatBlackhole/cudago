# Examples

This directory contains examples of how to use the `cuda` library wrapper in Go, and the CudaGo tool to generate wrappers for `.cu` files.

Every example assusmes that you have exported `CGO_CFLAGS` and `CGO_LDFLAGS` in your environment as described in [root README](../README.md).

Every example that uses __CudaGo__ assumes that you have built a CudaGo executable or installed it as decribed in [root README](../README.md).
